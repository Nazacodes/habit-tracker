Torn write leaves partial JSON → next load JSONDecodeError. Replace is atomic on same volume; temp prefix keeps readers from observing half file.

fd, tmp = tempfile.mkstemp(..., dir=path.parent)
try:
    ...
    os.replace(tmp, path)
finally:
    try: os.unlink(tmp)
    except OSError: pass
