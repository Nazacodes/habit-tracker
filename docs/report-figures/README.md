# Report figures (Habit Studio)

Static HTML figures for embedding in the Mini SDLC PDF.

## Capture

1. Open `index.html` (or individual `fig0X*.html`).
2. **PDF:** Chrome/Edge → `Ctrl+P` → Save as PDF.  
3. **Image:** Win+Shift+S → paste into Word.

Figure banner styling aligns with coursework document headers. Full prompt dialogue appears in **`../Prompt_Chats_Appendix.md`**.
