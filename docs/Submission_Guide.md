## Word (.docx) reports

### Final submission master (recommended)

Single Word file in marker order (SDLC, then prompt material, then reflection) plus supporting UI appendix:

```powershell
pip install -r requirements-docx.txt
python scripts/build_final_submission_docx.py
```

Produces `docs/docx/COMP8066_Final_Submission.docx`. Open in Word, confirm cover metadata (Chinaza, r002316262), paste Figure 1 through 5 where cited, then Save as PDF as `Chinaza-Ogwudiegwu_COMP8066_Assignment_1.pdf` if Moodle expects that casing.

Temporary Markdown used for Pandoc sits at `docs/.submission_compile.tmp.md` (ignored by git).

### Separate chapter files

Individual `.docx` per source file (when you prefer editing Markdown only per document):

```powershell
pip install -r requirements-docx.txt
python scripts/export_reports_to_docx.py
```

Older drafts used Mermaid in Markdown; raster PNG diagrams for Section 2 regenerate via scripts/make_diagram_pngs.py when you rebuild the submission doc.
